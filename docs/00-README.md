## The three things that must not drift

1. **The IR schema is frozen at H3.** TRD §4. Every service is a function over that object. Changing it mid-build costs the project.
2. **Colour is data.** Design Doc §2 and §5.1. Saturated colour means phase, probability, error or entanglement. Chrome is achromatic. One accent, three permitted uses.
3. **Grading compares states, never structure.** PRD §6.2, TRD §10. Two different correct circuits both pass, or the platform teaches ritual instead of understanding.

## The demo moment everything serves

Attempt a Bell state, omit the CNOT, and get back: *"q0 is in superposition, but q0 and q1 are still separable — add a CNOT with q0 as control and q1 as target."* Gate-specific, wire-specific, in under 200ms, with the language model switched off.

Ideation §18 has the full five-minute script. Rehearse it with `TUTOR_ENABLED=false` at least once.
