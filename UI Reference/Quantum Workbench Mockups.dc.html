RULE-BASED · NO MODEL CALL
Why is my output 01 and 10 instead of 00 and 11?

You put a Hadamard on q0, so q0 is in superposition — correct. But you then applied an X on q1, which flips q1 independently. The two wires never interact, so the state stays separable.

Replace the X with a CNOT, control q0 → target q1. That is the gate that couples them.

- qc.x(1)
+ qc.cx(0, 1)
